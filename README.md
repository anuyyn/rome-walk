# 로마 도보 6일

2026년 11월 16일~21일 로마 가족여행 도보 일정 지도.
매일 숙소(Fontana Più Stella)에서 출발해 같은 자리로 돌아오는 도보 루프입니다.

- 구글 3D 위성뷰 + 날짜별 실제 보행 경로
- 장소를 누르면 그 지점의 구글 거리뷰가 열림
- **따라 걷기**: 경로를 25 m 간격으로 전진하며 거리뷰를 자동 재생

## 실행에 필요한 것

`config.js` 파일에 Google Maps API 키가 있어야 합니다.

1. Google Cloud 콘솔에서 **Maps JavaScript API** 사용 설정
2. API 키 생성 → 웹사이트 제한에 이 페이지 주소 추가
3. `config.example.js`를 `config.js`로 복사하고 키를 넣기

**할당량 상한을 반드시 걸어두세요** (Maps Platform → 할당량).
따라 걷기 자동재생은 25 m마다 거리뷰를 1회 호출합니다.
